# Schach-Abenteuer

Schach-Rätsel für Kinder: Mattbilder, berühmte Fallen, Tricks und Kombinationen aus bekannten Partien (Morphy 1858, Réti 1910).

Neue Rätsel kommen in `puzzles.js`.

Schachregeln: [chess.js](https://github.com/jhlywa/chess.js) (BSD-2-Clause, siehe `vendor/chess.js-LICENSE.txt`).
